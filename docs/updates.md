# Подписанные обновления

Flow Studio 2.x проверяет последний обычный релиз `RichkovGit/GoogleFlowDesktop`. Предварительные и черновые релизы не устанавливаются. В релизе должны присутствовать `FlowStudio-update.json`, `FlowStudio-update.sig` и ZIP, указанный в подписанном манифесте.

В приложение встроен открытый ключ издателя. RSA-PSS/SHA-256 проверяется до чтения адреса пакета; затем проверяются версия, HTTPS, точный репозиторий, размер, SHA-256 пакета и версия EXE. ZIP распаковывается с запретом выхода из папки, абсолютных путей, ссылок, дубликатов и чрезмерного объёма. Google cookies и OAuth не передаются GitHub.

«Аккаунт и GPU» → «Проверить обновления» → «Скачать и установить». Фоновая проверка при старте только сообщает о доступной версии. После загрузки проект сохраняется и приложение закрывается. Новая программа запускается в режиме установки из временной папки, повторно проверяет подпись/ZIP, ждёт завершения прежнего процесса, заменяет файлы и перезапускается. При ошибке возвращает прежние файлы из резервной копии. Проекты, медиатека, DPAPI-вход и настройки находятся вне папки программы.

Для установки нужна доступная для записи папка приложения. Пакет рекомендуется распаковывать в пользовательский каталог. Обновления 2.x распространяются полным ZIP; старый однофайловый обновлятор 1.x не используется для миграции.

## Выпуск издателем

```powershell
.\build.ps1 -SelfContained -OutputDirectory .\artifacts\FlowStudio-2.0.1
.\tools\package-release.ps1 -Version 2.0.1
```

Закрытый ключ хранится за пределами репозитория в `%LOCALAPPDATA%\FlowStudioPublisher\update-key.bin`, защищён Windows DPAPI CurrentUser. Он не входит в сборку или GitHub. Перед выпуском проверьте self-test и реальные сценарии, затем загрузите три файла из `artifacts/release-<version>` в релиз с тегом `v<version>`. Скрипт подписания проверяет соответствие закрытого ключа открытому ключу, встроенному в программу. Ключ необходимо отдельно резервировать защищённым способом; его потеря не исправляется произвольной генерацией нового ключа для уже установленных клиентов.
