# Flow Studio 2.0 для Windows

Нативное приложение WPF / DirectX. Интерфейс, облачная медиатека и монтаж работают без встроенного браузера. Для отправки предусмотрены два варианта: прямой запрос Flow и отдельный служебный Chrome/Edge с собственным профилем приложения. Используется аккаунт Google Flow; Gemini API не подключён.

## Добавлено

- «Проекты Flow»: проекты аккаунта и медиатека всего аккаунта/текущего проекта. Оригиналы скачиваются при открытии; временные ссылки не записываются в проекты.
- Сохранённый вход Windows DPAPI и автоматическое восстановление из собственного профиля. Если Google требует пароль, код или проверку пользователя, это выполняет пользователь.
- Семейства моделей и отдельный выбор длительности/разрешения. Цены и доступность берутся из настоящего каталога для уровня аккаунта. Варианты с обязательными референсами не предлагаются для генерации только по тексту.
- «Монтаж»: порядок сцен, начало/конец, громкость, отключение звука, размер/FPS и MP4. Различающиеся исходники нормализуются, отсутствующий звук заменяется тишиной.
- NVIDIA NVENC, AMD AMF и Intel Quick Sync с реальной пробой кодировщика. CPU выбирается и разрешается отдельно; автоматического программного fallback нет.
- «Автоматизация»: папка новых видео, защита от дублей, автосклейка видео текущего проекта, реальные изменения баланса и уведомления Windows. Сохранённый запрос при пополнении ограничен числом генераций и бюджетом.
- «Агент Flow»: сеансы, история, инструкции с сохранением существующих связей с референсами, политика подтверждения и параметры генерации по умолчанию через настоящий сервис Flow.

## Проверенные сценарии и ограничения

Из приложения через служебный Flow подтверждены x1 Omni-видео 360p и 720p. Google подтвердил приём запросов; оригиналы скачаны и проверены FFmpeg: 640×360 и 1280×720, по четыре секунды. Агент Flow также создал три отдельных ролика 360p по десять секунд; оригиналы проверены и склеены в 30-секундный ролик через NVENC. Подробности — docs/verification.md.

Способ отправки выбирается в «Аккаунт и GPU». Прямой запрос может быть отклонён Google. Служебный браузер использует отдельный профиль и штатные элементы сайта; платные действия автоматически не повторяются. Сейчас драйвер поддерживает текст → видео Omni 1.1 Flash, 360p/720p, 4/6/8/10 секунд, x1–4. Другие семейства и референсы этим способом пока не отправляются. Новый формат подтверждений агента не разрешается автоматически.

Региональная совместимость касается только страны Flow. Возраст, вход, выход и проверки Google не подменяются. Полный паритет с меняющимся сайтом не заявляется; отдельные конструкторы персонажей/инструментов, облачный редактор сцен, upscale/GIF и публикация YouTube ещё не перенесены полностью. Карта функций: docs/flow-interface-audit.md.

Добавлены подписанные OTA: RSA-PSS, SHA-256, безопасная распаковка, сохранение проекта, перезапуск и откат файлов при ошибке. Подробнее: docs/updates.md. Для установки распакуйте весь ZIP релиза в доступную для записи папку. Самостоятельная сборка содержит .NET Runtime. Текущий исходник — src/FlowStudio; корневой прежний EXE относится к 1.x, для миграции используйте новый ZIP релиза.
## Начало работы

1. Запустите FlowStudio.exe или ярлык «Flow Studio».
2. «Аккаунт и GPU» → «Войти через Google». Пароль и коды вводятся только в обычном отдельном окне браузера. После входа откройте Flow и нажмите в приложении «Я вошёл — продолжить». Страница блокировки по стране не отменяет выполненный Google-вход: доступ проверяется нативными запросами.
3. В «Проекты Flow» откройте проект двойным щелчком. В медиатеке двойной щелчок скачивает оригинал и открывает нативный предпросмотр.
4. Добавляйте видео кнопкой «В сцену», затем открывайте «Монтаж». Обрезка не изменяет оригиналы.
5. В «Автоматизация» выберите папку и нужные действия, затем сохраните настройки. По умолчанию расход кредитов, автоскачивание и автосклейка выключены.

Мониторинг работает, пока приложение запущено, включая свёрнутое окно. Первое чтение задаёт исходный баланс. Увеличения +50/+1000 определяются по ответу Google; покупки и возвраты тоже могут увеличить баланс. Фиксированные начисления по календарю не обещаются; системные задания Windows не устанавливаются. Историческая медиатека целиком не скачивается при включении автосохранения.

## Хранение и GPU

Локальные проекты: Документы\Flow Studio. Облачные рабочие копии: %LOCALAPPDATA%\FlowStudio\CloudCache. Показываются только проекты, подтверждённые текущим аккаунтом. Настройки и журналы: %LOCALAPPDATA%\FlowStudio. Секреты отдельно защищены Windows DPAPI. Обычные браузерные профили не читаются; используется собственный LoginProfile приложения.

«Отключить аккаунт» удаляет сеанс из приложения, но не выполняет глобальный выход Google и не удаляет профиль входа. Локальные рабочие файлы не удаляются при смене аккаунта.

Генерация работает на серверах Google. Предпочтение дискретной GPU задаётся для EXE; адаптер WPF окончательно выбирает Windows. Сеть, файлы, часть фильтров и аудио используют CPU. Видеокодирование может выполняться через NVENC/AMF/QSV. Реально проверены NVENC и Intel QSV; AMD-карты на этом компьютере нет.

FFmpeg ищется в tools\ffmpeg.exe рядом с приложением, затем в пользовательском .local\bin. Сведения о GPU: docs/hardware.md; об автоматизации: docs/automation.md.

## Сборка и проверки

Для сборки нужен .NET 8 SDK; для обычной сборки при запуске — .NET 8 Desktop Runtime. SDK может находиться в .tools\dotnet.

```powershell
.\build.ps1
.\artifacts\FlowStudio\FlowStudio.exe --self-test
```

Самопроверка не обращается к аккаунту и не расходует кредиты. Отчёт: artifacts/self-test.json. Включены настоящие локальные GPU-экспорты. Границы проверки описаны в docs/verification.md.

Flow Studio — независимый клиент, не продукт Google.
